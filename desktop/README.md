# Facade Documents для Windows

Локальная программа КП/ПП. Сеть для работы не требуется. Интерфейс, шаблон BIFF8
и логотип включены в сборку. Сайт и база заявок не используются.

## Сборка и проверка

Node.js 22.12+; должны быть установлены зависимости основного репозитория (cfb).
В этой папке выполните `npm install`, затем `npm run build`.
Результат: `desktop/dist/Facade Documents-win32-x64`.
Передавайте всю папку в ZIP, вместе с инструкцией.

FACADE_BUILD_TOOLS позволяет задать отдельную папку с node_modules инструментов
сборки из package.json; FACADE_BUILD_OUTPUT — каталог результата.
Они нужны только во время сборки.

`npm test` проверяет XLS, округление, цены комплекта, формулы, 100 позиций,
валидацию, сохранение и резервные копии. Тесты создают отдельную временную папку;
путь можно задать через FACADE_TEST_OUTPUT.

## Данные

Заказы: каталог orders внутри Electron userData для Facade Documents.
Обычно Windows: `%APPDATA%/Facade Documents/orders`.
orders.json обновляется атомарно через временный файл. Предыдущая версия
остаётся в orders.json.bak. Программа запускается в одном экземпляре.
Импорт добавляет копии заказов и не заменяет существующие.

Генератор использует lib/crm/document-xls-template.json со встроенным логотипом,
добавляет строки и формулы ROUND/SUM с рассчитанными значениями.
Выбранный НДС обозначает введённые цены; налог дополнительно не вычисляется.

В Electron включены sandbox и contextIsolation, IPC проверяет источник.
Ресурсы локальные; сетевые запросы, внешняя навигация и разрешения заблокированы.
Сборка не имеет цифровой подписи издателя. Обновление выполняется вручную.
